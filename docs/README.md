# Documentation

**Trivor 0.5.0** includes Finder GLB thumbnails and interactive **Space** previews.
Quick Look automatically selects from four preview capacity tiers with 128–512 MiB
file budgets; background thumbnails use a fixed 64 MiB file budget. Start with
the [supported content and budgets](../quick-look/README.md#scope-and-limits) and
[compatibility notes](../quick-look/README.md#compatibility).

Download the current version from [GitHub Releases](https://github.com/imboni/trivor/releases/latest).
The minimum deployment target is macOS 13; release runtime tests used macOS 27.2
on Apple Silicon. Intel and older macOS runtime behavior were not tested for 0.5.0.
