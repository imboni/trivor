# Basis Universal transcoder

`basis_transcoder.js` and `basis_transcoder.wasm` are copied from
`three@0.182.0/examples/jsm/libs/basis` (the version pinned in `package-lock.json`).
Keep the JavaScript and WebAssembly files from the same release when updating.

Used by model-viewer's KTX2 loader so progressive texture previews work offline.
