FAQ

How do I install Trivor?

Download the DMG, drag Trivor to Applications, then launch it from Launchpad or Finder.

macOS says Trivor can't be opened — what should I do?

The current release is ad-hoc signed and has not been notarized by Apple. If macOS blocks it, try opening it once, then go to System Settings → Privacy & Security and choose Open Anyway for Trivor.

Which file formats are supported?

The app opens glTF and GLB, and imports OBJ and STL through conversion. Finder previews and thumbnails support self-contained GLB files only.

What are the system requirements?

macOS 13 Ventura or later. The universal app includes Apple Silicon and Intel builds; 0.5.0 was runtime-tested on macOS 27.2 with Apple Silicon.

How large can a Finder preview be?

Space previews use file budgets of 128, 256, 384 or 512 MiB, selected automatically. Decoded textures, geometry and scene complexity also count; memory or thermal pressure can lower capacity. Background thumbnails keep a 64 MiB file limit. Open larger models in the app for progressive previews.

How do I enable Finder previews?

Install Trivor 0.5.0 or later in Applications, select a self-contained GLB and press Space. If disabled, search System Settings for Extensions and enable Trivor GLB Preview and Trivor GLB Thumbnail under Quick Look. Other GLB extensions may affect which preview macOS uses.
